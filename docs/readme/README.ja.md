## 特徴

- Python で書かれた**プラグインシステム**と**プラグインプラザ**（最新ビルドにて）
- 今日の授業を**ウィジェット**として表示
- [授業リマインダー](https://www.yuque.com/rinlit/liumingclassroom_help/fv2ou1i1ngap0hrl)や予鈴、TTS音声出力対応
- **高いカスタマイズ性**のテーマシステム
- シンプルで直感的な[時間割エディター](https://www.yuque.com/rinlit/liumingclassroom_help/oozelh8r56tmw0xb)
- 複数の時間割ファイルを保存し、異なるデバイス間でインポート・エクスポートが可能
- [**CSES**](https://github.com/SmartTeachCN/CSES)によるフォーマット変換に対応
- [調整や授業変更](https://www.yuque.com/rinlit/liumingclassroom_help/gc4epffu7g5bf9os)へのクイックソリューション
- 「天気」や「カスタムカウントダウン」など実用的なウィジェット
- ["カスタム"](https://www.yuque.com/rinlit/liumingclassroom_help/qyly70ht1ogge1pi)でLiumingClassroomをパーソナライズ
- ライト/ダークテーマおよび**自動切り替え**対応<br>その他多数

## インストールと使い方

> [!TIP]
> [LiumingClassroom 公式ドキュメント](https://www.yuque.com/rinlit/liumingclassroom_help/gs3gsbms1iivgibm)でチュートリアルをご覧いただけます。

> [!IMPORTANT]
> このページで紹介されている機能を体験するには、 [**Actions**](https://github.com/rankfrank4010/liumingclassroom/actions) ページから LiumingClassroom をダウンロードしてください。

最新版の zip ファイルを ![Latest](https://img.shields.io/github/v/release/rankfrank4010/liumingclassroom?style=flat&color=purple&label=Latest) からダウンロードし、適切な場所に解凍後、`LiumingClassroom.exe` を実行してください。
設定やプログラムの終了はトレイメニューから行うことができます。
