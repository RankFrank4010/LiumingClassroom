## Features

- **Plugin System** and **Plugin Plaza** written in Python (latest builds)
- Displays today's courses as **widgets**;
- [Class reminders](https://www.yuque.com/rinlit/liumingclassroom_help/fv2ou1i1ngap0hrl) and prep bell, supports TTS voice out put;
- **High-customization** theme system.
- Simple and intuitive [class schedule editor](https://www.yuque.com/rinlit/liumingclassroom_help/oozelh8r56tmw0xb);
- Store multiple schedule files and import or export across LiumingClassroom on different devices;
- Supports [**Course Schedule Exchange Schema** (CSES)](https://github.com/SmartTeachCN/CSES) for conversion between formats;
- [Quick solutions](https://www.yuque.com/rinlit/liumingclassroom_help/gc4epffu7g5bf9os) for rescheduling or class changes;
- Practical widgets like "Weather", "Custom Countdown", etc;
- [Personalize](https://www.yuque.com/rinlit/liumingclassroom_help/qyly70ht1ogge1pi) your LiumingClassroom via "Custom";
- Light or Dark theme support and **auto switch**,<br>and so on.

## Installation & Usage

> [!TIP]
> Tutorials available at [LiumingClassroom Official Documentation](https://www.yuque.com/rinlit/liumingclassroom_help/gs3gsbms1iivgibm).

> [!IMPORTANT]
> To experience the features on this page, please download LiumingClassroom from the [**Actions**](https://github.com/rankfrank4010/liumingclassroom/actions) page.

Download the latest zip file from the ![Latest Version](https://img.shields.io/github/v/release/rankfrank4010/liumingclassroom?style=flat&color=purple&label=Latest), extract it to a suitable location, and run `LiumingClassroom.exe`.
You can access settings or exit the program via the tray menu.
